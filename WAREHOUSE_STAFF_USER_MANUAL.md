## 1. Getting Started

### What Can Warehouse Staff Do?

As warehouse staff, your primary responsibilities in the system are:

- **View equipment inventory** - See all equipment in warehouse
- **Track equipment location** - Record where equipment is physically stored
- **Update equipment status** - Mark equipment as available, in use, storage, etc.
- **Record equipment movement** - Track when equipment moves
- **View equipment requests** - See requests from users and supervisors
- **Approve equipment requests** - Review and approve equipment requests
- **Reject equipment requests** - Deny requests with explanation
- **Process equipment assignments** - Prepare equipment for new users
- **Transfer equipment** - Move equipment between departments/users
- **Track equipment condition** - Update condition status (good, fair, poor)
- **Generate inventory reports** - Create reports on warehouse stock
- **Manage asset returns** - Handle equipment returns from users
- **Conduct physical inventory counts** - Verify actual stock matches system

### What Can't Warehouse Staff Do?

Warehouse staff cannot:
- Create user accounts
- Modify system settings
- Delete equipment records
- Access restricted company data
- Change their own permissions
- Create tickets for non-warehouse issues
- Approve requests outside warehouse scope
- Override administrator decisions
- Access other departments' private information

### Warehouse Responsibilities

As warehouse staff, you are responsible for:

- **Inventory Accuracy** - Keeping equipment records updated and accurate
- **Location Tracking** - Knowing where equipment is at all times
- **Request Processing** - Quickly handling equipment requests
- **Equipment Care** - Properly storing and handling equipment
- **Condition Monitoring** - Tracking equipment condition
- **Documentation** - Recording all movements and transfers
- **Organization** - Keeping warehouse organized
- **Security** - Protecting equipment from theft or damage
- **Communication** - Keeping others informed about equipment
- **Compliance** - Following warehouse procedures

## 2. Logging In

### First Time Login

1. Open your web browser and navigate to the IT Help Desk System URL
2. You will see the login page
3. Enter your warehouse staff username
4. Enter your initial password
5. Click the **Login** button
6. You will be prompted to change your password
7. Enter a new password (at least 6 characters)
8. Confirm the new password
9. Click **Change Password**
10. You will see the Warehouse Dashboard
11. You are now ready to work with inventory

### Subsequent Logins

1. Navigate to the login page
2. Enter your username
3. Enter your password
4. Click **Login**
5. You will be taken to the Warehouse Dashboard

### Forgot Your Password?

1. Click **Forgot Password?** on login page
2. Enter your email or username
3. Click **Reset Password**
4. Check your email for reset link
5. Click the link
6. Enter new password
7. Confirm password

- Use your official warehouse username
- Passwords are case sensitive
- Change password every 90 days

## 3. Understanding Inventory Management

### Warehouse Inventory System

The warehouse inventory system tracks:

- **All Equipment** - Computers, monitors, printers, peripherals, licenses
- **Location** - Where equipment is stored in warehouse
- **Status** - Available, in use, storage, repair, disposed
- **Condition** - Good, fair, poor, broken
- **Assignment** - Who has the equipment
- **History** - Where equipment has been and who used it
- **Maintenance** - Repair and service records
- **Value** - Original cost and current depreciation

### Equipment Tracking Overview

Every piece of equipment has:

- **Asset Code** - Unique identifier (e.g., DELL-LAP-0154)
- **Equipment Name** - What it is (Dell Latitude Laptop)
- **Category** - Type (Computer, Monitor, Printer, etc.)
- **Status** - Current state in warehouse
- **Condition** - Physical condition
- **Location** - Current storage location
- **Assigned To** - Current user (if in use)
- **Purchase Date** - When acquired
- **Value** - Original and current value
- **Maintenance History** - All repairs and service
- **Movement History** - All transfers and changes

### Asset Codes and Organization

Asset codes are critical for tracking:

**Format Example**: DELL-LAP-0154
- **DELL** - Manufacturer
- **LAP** - Equipment type (laptop)
- **0154** - Sequential number

**Organization in Warehouse:**

The warehouse is organized by:
1. **Category** (Computers, Monitors, Printers, etc.)
2. **Manufacturer** (Dell, HP, Lenovo, etc.)
3. **Type** (Desktop, Laptop, Monitor, etc.)
4. **Condition** (Good, Fair, Poor)
5. **Shelf/Location** (A-1, A-2, B-1, etc.)

### Condition and Status Tracking

**Condition Status:**
- **Good** - Equipment working normally, ready to use
- **Fair** - Equipment working but may need maintenance
- **Poor** - Equipment working but needs repair soon
- **Broken** - Equipment not working, needs repair
- **Disposed** - Equipment no longer usable

**Location Status:**
- **Available** - In warehouse, ready for assignment
- **In Use** - Currently assigned to a user
- **In Storage** - Stored in warehouse (awaiting use)
- **In Repair** - Currently being repaired
- **In Transit** - Being moved/transferred
- **Returned** - Back from user, pending processing

## 5. Tracking Equipment Location and Movement

### Recording Equipment Location

When equipment arrives in warehouse:

1. Go to **Inventory** → **New Equipment**
2. Or open existing equipment
3. Click **Update Location**
4. Enter location details:
   - **Building** - Which building (if multiple)
   - **Warehouse Section** - Which section (A, B, C, etc.)
   - **Shelf/Aisle** - Specific shelf location (A-1, A-2, B-1, etc.)
   - **Bin** - Specific bin number if applicable
5. Click **Save Location**
6. Equipment location is updated
7. Add a note: "Received new shipment and stored in section A, shelf 3"

**Example Location Format:**
```
Building: Main Building
Section: Warehouse A
Shelf: Row 3, Shelf 2
Bin: Position 5
Full Location: A-3-2-5
```

### Updating Equipment Status

1. Open equipment record
2. Look for **Status** field
3. Click to change:
   - **Available** - Equipment is ready for use
   - **In Use** - Equipment assigned to user
   - **In Storage** - Equipment stored, not in use
   - **In Repair** - Equipment being repaired
   - **In Transit** - Equipment being moved
   - **Returned** - Equipment returned from user
4. Click **Save**
5. Status is updated immediately
6. Status change is recorded with timestamp

### Tracking Equipment Transfers

When equipment moves to a new user:

1. Open equipment record
2. Click **Transfer Equipment** or **Change Assignment**
3. Confirm previous assignment (who had it)
4. Select new assignment (who gets it)
5. Enter transfer date
6. Add notes about the transfer
7. Click **Complete Transfer**
8. System records:
   - Previous user
   - New user
   - Transfer date
   - Who processed transfer
   - Any notes

**Example Transfer:**
```
Equipment: Dell Laptop (DELL-LAP-0154)
From: John Smith (Sales Department)
To: Sarah Johnson (Marketing Department)
Date: 2026-06-08 10:00 AM
Note: Equipment transferred per department change request
Status Updated: In Transit (then) → In Use (when delivered)
```

### Recording Equipment Movement History

The system automatically tracks all movement:

1. Open equipment record
2. Click **View Movement History**
3. You see all movements:
   - Date and time
   - From location/person
   - To location/person
   - Who processed it
   - Notes
   - Status before and after

**Example Movement History:**
```
2026-06-08 10:00 AM: Transferred from John Smith to Sarah Johnson
2026-06-07 03:00 PM: Received shipment, stored in A-3-2
2026-06-06 02:00 PM: Equipment in transit from warehouse
2026-06-05 09:00 AM: New equipment received and logged
```

### Physical Inventory Counts

Conduct regular physical inventory:

1. Go to **Inventory** → **Physical Count**
2. Or print equipment list by location
3. Go to each location in warehouse
4. Count actual equipment present
5. Mark off in system as you count
6. Compare actual count to system count
7. Investigate discrepancies:
   - Equipment in wrong location
   - Equipment not in system
   - System shows equipment not present
8. Update locations/status as needed
9. Generate discrepancy report
10. Document findings

## 6. Processing Equipment Requests

### Understanding Equipment Requests

Equipment requests come from:

1. **New Employees** - Need equipment for new hire
2. **Department Requests** - Supervisor requesting equipment for team
3. **Replacements** - User requesting replacement for broken equipment
4. **Upgrades** - User requesting upgraded equipment
5. **Returns** - Equipment being returned to warehouse

**Request Information:**
- Who requested it
- What equipment they want
- When they need it
- Why they need it
- Department
- Manager approval (if required)

### Viewing Pending Requests

1. Go to **Requests** or **Equipment Requests**
2. Click **Pending Approval**
3. You see all requests waiting for warehouse approval
4. Shows:
   - Request ID
   - Requested by
   - Equipment type
   - Requested date
   - Needed by date
   - Status
5. Requests are listed by date

### Reviewing Request Details

1. Click on a request to open it
2. You see full details:
   - **Requester** - Who submitted it
   - **Department** - Which department
   - **Equipment Type** - What they want
   - **Quantity** - How many items
   - **Reason** - Why they need it
   - **Needed By** - Date required
   - **Supervisor Approval** - Is supervisor approved?
   - **Priority** - Urgency level
   - **Notes** - Any additional information
3. Check warehouse inventory:
   - Is equipment available?
   - In what condition?
   - Where is it located?
4. Determine if request can be approved

### Request Types and Categories

**New Hire Equipment:**
- Computer (desktop or laptop)
- Monitor(s)
- Keyboard and mouse
- Other peripherals
- Requires supervisor approval
- Should be marked "High Priority"

**Replacement Equipment:**
- User's equipment broke
- Needs immediate replacement
- Check if broken equipment is repairable
- Assign similar replacement if available

**Upgrade Request:**
- User wants better equipment
- More subjective approval
- Check supervisor approval
- Verify need justification

**Returns:**
- User returning equipment
- Equipment damaged or end of life
- Assess condition
- Determine if reusable or dispose

## 7. Approving Equipment Requests

### Understanding Approval Workflow

The approval process:

1. **Supervisor Approval** (if required)
   - Supervisor reviews and approves/rejects
   - Submits to warehouse
2. **Warehouse Approval**
   - Warehouse reviews inventory
   - Checks equipment availability
   - Approves or rejects
   - Sets timeline
3. **Processing**
   - Warehouse prepares equipment
   - Updates system
   - Arranges delivery/pickup
4. **Fulfillment**
   - Equipment delivered
   - User receives and confirms
   - Request closed

### Reviewing Requests for Approval

Before approving:

1. **Check Supervisor Approval**
   - Is supervisor already approved?
   - If no, should you wait or contact them?

2. **Verify Inventory**
   - Is requested equipment available?
   - In what condition?
   - Where is it stored?

3. **Check Quantity**
   - Do we have enough?
   - Can we fulfill request?
   - What's the timeline?

4. **Review Justification**
   - Is the request reasonable?
   - Does need match equipment?
   - Is priority appropriate?

5. **Check Department Budget** (if applicable)
   - Does department have budget?
   - Any budget restrictions?

### Approving Equipment Requests

To approve a request:

1. Open the request
2. Verify all details are correct
3. Confirm inventory is available
4. Click **Approve Request**
5. System asks you to confirm
6. Select timeline:
   - **Today** - Available immediately
   - **Tomorrow** - Available next day
   - **Custom Date** - Specify date
7. Add approval comment:
   - "Equipment available in stock. Ready for pickup."
   - "Dell Laptop (DELL-LAP-0154) available. In good condition."
8. Click **Confirm Approval**
9. Status changes to **Approved**
10. Requester and supervisor are notified
11. Equipment is marked as "Pending Assignment" in system

**Approval Details Recorded:**
```
REQUEST APPROVED
────────────────
Request ID: REQ-5234
Equipment: Dell Laptop
Approved By: Maria (Warehouse Staff)
Approval Date: 2026-06-08 10:15 AM
Approval Timeline: Available 2026-06-08
Status: Ready for Pickup/Delivery
Condition: Good
Equipment Code: DELL-LAP-0154
Notes: "Equipment in inventory, ready immediately"
```

### Rejecting Equipment Requests

If equipment not available or request invalid:

1. Open the request
2. Click **Reject Request**
3. System asks for reason
4. Select rejection reason:
   - "Equipment not currently available"
   - "Equipment in repair"
   - "Insufficient inventory"
   - "Request requires director approval"
   - "Custom reason"
5. Add detailed comment:
   - "All Dell laptops currently in use. Equipment available in 2 weeks."
   - "Requested equipment is being repaired. Will be available next week."
   - "Request exceeds department budget. Contact supervisor."
6. Click **Confirm Rejection**
7. Status changes to **Rejected**
8. Requester is notified with reason
9. Request can be resubmitted later

**Rejection Details Recorded:**
```
REQUEST REJECTED
────────────────
Request ID: REQ-5235
Equipment: 3 Dell Monitors
Rejected By: Maria (Warehouse Staff)
Rejection Date: 2026-06-08
Reason: Insufficient inventory
Notes: "Only 1 monitor available. 2 monitors currently assigned to
users. Request again in 1 week when returns expected."
```

### Adding Approval Comments

Add comments to provide information:

1. Open request
2. Go to **Comments** section
3. Click **Add Comment**
4. Type your message:
   - "Equipment is in good condition and immediately available."
   - "We have 2 of the 3 monitors requested. Can provide 2 now and 1 next week."
   - "Equipment has been located in warehouse section A-2. Ready for pickup at dock."
5. Click **Add Comment**
6. Comment is visible to requester and supervisors
7. Timestamp shows when comment added

### Tracking Approval Timeline

The system tracks approval dates:

**Key Timeline Points:**

```
REQUEST TIMELINE
────────────────
Submitted: 2026-06-07 02:00 PM (by User)
Supervisor Approval: 2026-06-07 03:30 PM (by Supervisor)
Warehouse Approval: 2026-06-08 10:15 AM (by Warehouse Staff)
Approved Duration: 20 hours from submit to warehouse approval
Target Delivery: 2026-06-08 04:00 PM
Status: APPROVED ✓
```

You can see:
1. When request was submitted
2. When supervisor approved
3. When you approved in warehouse
4. How long approval took
5. When it will be ready
6. Current status

## 8. Managing Equipment Condition

### Assessing Equipment Condition

When receiving equipment or during inventory:

1. **Visually Inspect:**
   - Check for physical damage
   - Look for cracks, dents, discoloration
   - Check ports and connections
   - Look for missing parts or stickers

2. **Functionally Test:**
   - Power on equipment
   - Test basic functions
   - Check all ports work
   - Verify no error codes
   - Check for unusual sounds

3. **Document Findings:**
   - Take notes of any issues
   - Note damage locations
   - Estimate repair difficulty
   - Determine if usable or needs repair

### Updating Condition Status

1. Open equipment record
2. Click **Update Condition**
3. Select condition status:
   - **Good** - No issues, fully functional
   - **Fair** - Works but may have minor wear/issues
   - **Poor** - Working but needs maintenance soon
   - **Broken** - Not working, needs repair
4. Add condition notes:
   - "Small dent on side, doesn't affect function"
   - "Keys occasionally stick, needs cleaning"
   - "Battery not holding charge, needs replacement"
5. Click **Save Condition**
6. Status is updated

### Documenting Damage or Issues

1. Open equipment record
2. Click **Add Damage Note**
3. Document:
   - **Damage Type** - Scratch, dent, broken part, etc.
   - **Location** - Where on equipment
   - **Severity** - Minor, moderate, major
   - **Description** - Detailed explanation
   - **Date Found** - When damage was discovered
   - **Impact** - Does it affect functionality?
4. Click **Save**
5. Damage is recorded in equipment history
6. Important for future users to know about

### Marking Equipment for Repair

If equipment needs repair:

1. Open equipment record
2. Click **Create Repair Request**
3. Fill in repair details:
   - **Issue** - What needs repair
   - **Urgency** - How soon needed
   - **Notes** - Additional details
4. System creates a repair ticket
5. Update equipment status to **In Repair**
6. Notify IT maintenance team
7. Track repair progress
8. Update condition once repaired

### Tracking Maintenance Status

1. Open equipment record
2. Click **Maintenance History**
3. View all maintenance performed:
   - Date
   - Type (repair, cleaning, update)
   - Description
   - Technician
   - Cost
   - Status
4. Use this to:
   - Understand equipment history
   - Plan future maintenance
   - Estimate when replacement needed
   - Track repair costs

## 9. Equipment Assignments and Transfers

### Preparing Equipment for Assignment

When equipment will be assigned to a user:

1. Locate equipment in warehouse
2. Perform condition check
3. Ensure in good working order
4. Clean equipment if needed

- [ ] Equipment functions properly
- [ ] All cables and accessories included
- [ ] No physical damage
- [ ] Software installed and licensed
- [ ] Equipment cleaned
- [ ] System information documented
- [ ] Asset code visible/applied

### Recording New Assignments

When assigning equipment to new user:

```
EQUIPMENT ASSIGNMENT

Asset: Dell Laptop (DELL-LAP-0154)
```

2. Click **Transfer Equipment**

4. Select new user
5. Enter transfer date
6. Transfer reason:
   - "Employee transferred to different department"
   - "Equipment replacement for failed unit"
   - "User returned, assigned to new user"
7. Click **Complete Transfer**
8. Previous user is notified
9. New user is notified
10. Equipment status stays **In Use**
11. Assignment history updated

### Decommissioning Equipment

When equipment reaches end of life:

1. Open equipment record
2. Click **Decommission Equipment**
3. Select reason:
   - "End of life"
   - "Obsolete"
   - "Damaged beyond repair"
   - "Recycled"
4. Enter decommission date
5. Add notes:
   - "Equipment deprecated, replaced with newer model"
   - "Hard drive failure, data recovery completed"
6. Click **Confirm Decommission**
7. Equipment status changes to **Disposed**
8. Equipment no longer appears in available inventory
9. Historical records preserved for audit

### Returning Equipment

When user returns equipment:

1. Receive equipment from user
2. Check for damage/issues
3. Update condition status
4. Clean equipment if needed
5. Update equipment status to **Returned**
6. Click **Update Assignment** - Remove user
7. Equipment is now unassigned
8. Status becomes **Available**
9. Location updated to warehouse location
10. Equipment ready for reassignment

## 10. Common Warehouse Tasks

### Task: Receiving New Equipment Shipment

**Scenario**: Shipment of 10 new Dell laptops arrives at warehouse

**Steps:**

1. Receive delivery
2. Compare packing slip to purchase order
3. Count equipment - verify 10 laptops present
4. Verify serial numbers match
5. Inspect for damage during shipping
6. Log into system
7. Go to **Inventory** → **Receive New Equipment**
8. For each laptop:
   - Asset Code: DELL-LAP-[0155-0164]
   - Equipment Name: Dell Latitude 5000
   - Category: Computer - Laptop
   - Serial Number: [from equipment]
   - Condition: Good
   - Status: Available
   - Location: Warehouse A, Section 2, Shelf 1
   - Notes: "New shipment received 2026-06-08"
9. Save all 10 items
10. Update inventory counts
11. Notify department of availability
12. Equipment ready for assignment

### Task: Processing Equipment Request

**Scenario**: Manager requests 3 monitors for new hires

**Steps:**

1. Request submitted: "Need 3 monitors for Marketing dept new hires"
2. Check inventory: 5 monitors available in warehouse
3. All in good condition
4. Open the request
5. Verify supervisor already approved
6. Click **Approve Request**
7. Timeline: "Available today"
8. Add comment: "3 HP monitors available in stock, good condition. Ready for pickup at dock entrance at 4:00 PM"
9. Confirm approval
10. System notifies requester and supervisor
11. Monitors marked as "Pending Assignment"
12. Arrange for user pickup or delivery
13. User confirms receipt
14. Update equipment status to **In Use**
15. Assignment confirmed in system

### Task: Transferring Equipment Between Departments

**Scenario**: Transferring 5 computers from IT Dept to Sales Dept

**Steps:**

1. IT Department returns equipment
2. Receive equipment at warehouse
3. Inspect condition - all good
4. For each computer:
   - Update status from **In Use** to **Returned**
   - Remove IT user assignment
   - Update location to warehouse
   - Check condition
5. Update equipment status to **Available**
6. Sales Department submits equipment request for 5 computers
7. Check warehouse availability - equipment available
8. Approve request: "Equipment available immediately"
9. Sales Dept picks up equipment
10. For each computer:
    - Click **Assign Equipment**
    - Select Sales Dept user
    - Mark status **In Use**
    - Set location to user's office
11. Update assignment in system
12. Transfer complete

### Task: Conducting Physical Inventory

**Scenario**: Monthly physical inventory count

**Steps:**

1. Print inventory list organized by location
2. Go to Warehouse Section A:
   - Shelf 1: Found 5 computers (system shows 5) ✓
   - Shelf 2: Found 3 monitors, 1 missing (system shows 4) ✗
3. Investigate discrepancy:
   - Check if equipment transferred but not updated
   - Check if equipment in repair but not marked
   - Create request to locate missing monitor
4. Go to Warehouse Section B:
   - All equipment accounted for ✓
5. Go to Warehouse Section C:
   - Found 2 computers not in system (orphan equipment)
   - Add to system immediately
6. Complete count for all sections
7. System automatically compares counts
8. Discrepancy report generated:
   - 1 monitor missing - investigate
   - 2 computers not cataloged - add
9. Address issues:
   - Find missing monitor or write off
   - Catalog orphan equipment
10. Re-verify after corrections
11. Inventory count now accurate
12. Generate final count report

### Task: Generating Inventory Report

## 11. Troubleshooting and Maintenance

### Equipment Not Found in System

**Problem**: Physical equipment found in warehouse but not in system

**Solution**:
1. Check if equipment is in system under different name
2. Search by partial equipment name
3. Search by serial number
4. Check if equipment marked as disposed
5. If truly not in system:
   - Go to **Add Equipment**
   - Enter all details
   - Assign asset code
   - Add to inventory
6. Investigate how equipment came to warehouse
7. Document in system

### Inventory Discrepancies

**Problem**: System shows equipment, but not found in physical count

**Solution**:
1. Double-check location in system
2. Equipment may be in different location than recorded
3. Check if equipment is assigned to user (no longer in warehouse)
4. Check if equipment marked as In Repair
5. Check if equipment marked as In Transit
6. If truly missing:
   - Mark as missing in system
   - Search warehouse again
   - Update status to "Missing" with date
   - Create incident report
   - Notify supervisor
7. File loss claim if applicable

### Lost or Missing Equipment

**Problem**: Equipment cannot be located

**Solution**:
1. Verify equipment details in system
2. Check with supervisors - do they have it?
3. Check if improperly transferred
4. Review movement history
5. Post notice asking about equipment
6. Contact department heads
7. If not found after investigation:
   - Update status to **Lost**
   - Document loss with date
   - Create incident report
   - Notify finance/accounting
   - File loss report
   - Update inventory value
   - Consider insurance claim

### Damaged Equipment Handling

**Problem**: Equipment received with damage

**Solution**:
1. Inspect damage extent
2. Document damage:
   - Take photos
   - Describe in detail
   - Note if shipment was damaged
3. Check if damage occurred in transit
4. Determine if equipment repairable
5. If shipping damage:
   - File claim with shipping company
   - Request replacement from vendor
   - Document claim process
6. If equipment usable:
   - Mark condition accordingly
   - Note damage in system
   - Assign to user (note the condition)
7. If not usable:
   - Create repair request
   - Mark status In Repair
   - Track repair process
   - Update condition when repaired

### Request Processing Issues

**Problem**: Request stuck or not processing

**Solution**:
1. Check if supervisor approval needed
2. If no supervisor approval, contact supervisor
3. Check equipment availability
4. If equipment not available, review timeline with requester
5. Check if request rejected - review reason
6. Contact requester about status
7. Provide update on timeline
8. Process request once issues resolved
